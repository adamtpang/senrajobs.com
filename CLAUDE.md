# senrajobs.com 🪜

Free fan site: every living founder David Senra interviews, their companies, and careers links.
Join a great founder, learn from inside, then build your own.

- Stack: plain static HTML (index.html) + guests.json data. No build step. Template exception: trivial single-file static page.
- Data source of truth: GUESTS.md (research) compiled into guests.json. Only verified careers links get a link.
- One to one: local folder, GitHub adamtpang/senrajobs.com, Vercel project senrajobs.com, shared PostHog.
